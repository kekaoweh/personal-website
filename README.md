# kekwebsite

Personal portfolio for Kekachukwu Oweh — live at [kekwebsite.vercel.app](https://kekwebsite.vercel.app).

Built with Next.js, TypeScript and Tailwind CSS, deployed on Vercel.

## Editing content

All text — bio, experience, projects, skills, education and links — lives in
[`src/content/site.ts`](src/content/site.ts). Edit it and push; Vercel redeploys automatically.

## Running locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

Pages: `/` (home), `/projects`, `/resume` (printable — "Download PDF" saves it via the print dialog).
Keyboard shortcuts: `h` home, `p` projects, `r` résumé, `t` theme, `a` accent color.
